| 项 | 做法 | 验证 |

## 六、已验证有效

1. 原文串区间替换 → 三本结构零破坏；
2. 术语表 + NameResolver → 同一实体全书一种译名；
3. 多轮修订（只改 accuracy+major）→ 修掉硬错误且不改坏；
4. 丢弃注音 → 标记量 -98.5%，最难的篇 token 降 4.4 倍；
5. 跨章一致性检查 → 抓出「イナテン 8 种译法」「ナベシン 8 种译法」；
6. 预读 → 人物召回 12/13，并发现未列角色与绰号；
7. 自动修复 → 26 处标点、21 段重译，术语类待办清零；
8. 内容哈希缓存 → 重复请求 0.18s 命中。

## 五、验证失败 / 已推翻

1. **风险分级路由**：表层特征无法预测问题段落（覆盖 6% 只抓 15%）；
2. **三层记忆**：块级 A/B 仅 50→46，价值在跨章一致性而非单段；
3. **别名自动定名**：模型会重新发明译名，必须人工确认；
4. **时间线矛盾检测**：事件级抽取缺失，检测不成立（用户也判定此需求价值低）。
